# LN1 — Comprehensive Spoken Lecture Narrations

Bachelor of Artificial Intelligence and Robotics Engineering — complete spoken lecture narration scripts for all 48 course subjects (AI 101 – AI 450), written in simple English with real-life practicals.

## What is included

Each course has one TXT file containing a comprehensive spoken lecture narration:

- **5,000+ words per course** (40–45 minutes of speaking time)
- **Simple English**, written to be read aloud or used for text-to-speech
- **Real-life practicals**, examples, mini-project guides, glossaries, and study questions with model answers
- Structured in numbered parts with a course header and closing recap
